# 家庭記帳手冊

手機版網頁 App，使用 Node.js 24 與 SQLite。啟動後由媽媽建立四個帳號，再各自登入。預設使用新台幣與台北日期。

## 在這台電腦啟動

先試填時，可以用免登入共用模式：

```powershell
$env:LEDGER_SHARED = '1'
node server.mjs
```

共用模式限本機使用。能開啟頁面的人都能查看、編輯及匯出整份帳。每筆可選登記者與歸屬。日後要啟用四人帳本，在啟動前執行 `Remove-Item Env:LEDGER_SHARED -ErrorAction SilentlyContinue`，原有紀錄會依登記者和歸屬顯示。

### 四人登入模式

在程式資料夾開啟 PowerShell：

```powershell
node server.mjs
```

開啟 http://127.0.0.1:8787，輸入終端機上的首次設定代碼，為四人設定各自不同的 4 至 8 位數字密碼。資料儲存在 `data/ledger.sqlite`。停止程式後可以備份整個 `data` 資料夾。

四人共用同一台伺服器。若要讓各自手機登入，請透過 HTTPS 反向代理提供私人網址，並在啟動前設定 `LEDGER_SECURE_COOKIE=1`。預設服務只聽本機。

## 拍照辨識

在執行 App 的電腦上啟動 Ollama，下載支援圖片輸入的模型。將下方的模型名稱換成已下載的名稱，再啟動程式。

```powershell
$env:LEDGER_OCR_MODEL = '已下載的視覺模型名稱'
node server.mjs
```

App 把 JPEG、PNG 或 WebP 照片送到同台電腦的 Ollama。原圖會在當次核對畫面顯示，重新整理或登出後須重新上傳。核對日期、項目和金額後逐筆入帳。可先拿一頁手寫帳及一頁信用卡帳單確認模型辨識品質。

## 每月記帳

- 媽媽替女兒付費時，填寫一次並把支出歸給該女兒。女兒登入能看到這筆代付，卡片暱稱只顯示給登記者與媽媽。
- 家庭共同開銷選「全家共同」。LINE Pay 綁卡可填支付方式「LINE Pay」，再填信用卡暱稱。
- 信用卡消費按消費日入帳。繳卡費記為「帳戶移轉」，零用錢記為「家人轉帳」。全家損益表會排除這兩種類型。
- 出現重複提示時，核對日期、金額和交易後再決定是否另存。退款填正金額、選「退款」，並沿用原消費的分類及歸屬。
- 媽媽切換月份就能查看全家收入、分類與成員支出、共同支出及結餘。

## 匯出到媽媽的 Google 試算表

媽媽選定月份後，按「匯出本月 CSV」，再到私人 Google 試算表使用「檔案 → 匯入」上傳 CSV。建議匯入為新分頁，並關閉將文字轉換為數字、日期及公式的選項。CSV 包含該月四人的收支明細，請由媽媽保管。家庭損益表可直接在 App 查看。

## 選用的 Google 試算表自動同步

1. 媽媽建立一份私人 Google 試算表，新增一個空白分頁，例如「家庭記帳明細」。網址 `/d/…/edit#gid=…` 中可找到試算表 ID 和該分頁的 gid。
2. 在 Google Cloud 啟用 Google Sheets API，建立服務帳戶並下載 JSON 金鑰。將試算表以「編輯者」權限分享給金鑰中的服務帳戶電子郵件。金鑰留在自己電腦，請勿上傳或提交到 Git。試算表的一般存取權保持「受限制」，其他家人透過 App 查詢自己的帳。
3. 在 PowerShell 設定三個值，啟動程式：

```powershell
$env:LEDGER_SHEET_ID = '試算表 ID'
$env:LEDGER_SHEET_GID = '專用分頁 gid'
$env:LEDGER_GOOGLE_CREDENTIALS = 'C:\私人資料夾\服務帳戶金鑰.json'
node server.mjs
```

啟動時同步既有紀錄，新增、編輯及刪除會自動更新試算表。網路中斷時可繼續記帳，程式會重試。同步使用專用分頁的 A 到 J 欄，這些欄位會依 App 資料覆寫。請在 App 修改收支；Google 試算表上的修改不會寫回 App。帳號和登入資料保留在本機。
