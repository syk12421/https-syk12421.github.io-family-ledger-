# 換電腦接續家庭記帳手冊

1. 將 ZIP 解壓縮到新電腦，在解壓縮後的資料夾開啟 PowerShell。
2. 確認已安裝 Node.js 24。執行下面兩行，讓 PowerShell 視窗保持開啟。

```powershell
$env:LEDGER_SHARED = '1'
node server.mjs
```

3. 在新電腦開啟 http://127.0.0.1:8787/。在月份選擇 2026 年 11 月即可查看現有試填資料。

若要繼續改程式，用 Codex 開啟這個資料夾，再描述下一個修改。可貼上：「接續這個家庭記帳手冊專案。先讀 README.md 和現有程式，保留 data/ledger.sqlite，再依我的下一個需求調整。」

目前為免登入共用模式，每筆可選登記者與收支歸屬。月報可一鍵列印或存成 PDF，支援分類占比、與上月比較、點分類查看明細及 CSV 匯出。拍照辨識需要在新電腦設定 Ollama。Google 試算表可手動匯入 CSV，也可按 README 設定自動同步。

ZIP 含目前帳本，請私下傳送。若兩台電腦都繼續新增資料，兩份帳會各自更新。搬家後可集中在新電腦記帳。
